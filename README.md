# Smart Academic Registration Advisor

A rule-based decision-support system that helps university students make informed course registration decisions based on their academic record and the faculty's official academic regulations.

## Overview
The system analyzes a student's cumulative GPA, passed courses and failed courses, validates registration eligibility, and generates registration plans with a clear explanation for every recommendation or restriction. It recommends only and never enrolls students automatically.

## Key Features
- Student academic profile and course catalog management
- Prerequisite, GPA and credit-hour eligibility checking
- Failed-course handling according to faculty regulations
- Course prioritization and registration plan generation
- Comparison of alternative plans with explanations
- Advisor review for exceptional cases
- Administrative management of academic rules

## User Roles
Student, Academic Advisor, Administrator
